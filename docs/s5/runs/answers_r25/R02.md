### 1) 结论  
老年AML患者中，**年龄≥75岁、一般情况差或具有不良预后因素者**（如不良染色体核型、前期血液病史、治疗相关性AML），**不适合强化疗**，应选择**低强度治疗方案**或支持治疗。具体推荐如下:

| 治疗策略 | 推荐方案 | 剂量与疗程 | 关键疗效/适用说明 |
|----------|-----------|-------------|------------------|
| **低强度化疗** | 地西他滨单药 | 20 mg/(m²·d)，连续5–10天为1个疗程 | 2017年中国AML指南推荐首选方案之一 [ID:bad3c8da91f42b22] |
| | 小剂量化疗±G-CSF（CAG/CHG/CMG等） | C：阿糖胞苷；A：阿克拉霉素；H：高三尖杉酯碱；M：米托蒽醌；具体剂量未详述 | 同上 [ID:bad3c8da91f42b22] |
| | 地西他滨联合小剂量化疗 | 方案组合未详述 | 同上 [ID:bad3c8da91f42b22] |
| **支持治疗** | 成分输血、抗感染、防治尿酸性肾病、纠正出凝血障碍等 | 血小板维持≥10×10⁹/L（发热时≥20×10⁹/L）；别嘌醇预防尿酸肾病；及时经验性抗生素 | [ID:d7ca255fcb9633f9] |
| **缓解后治疗（若达CR）** | 标准剂量化疗巩固 | 如标准Ara-C 100–200 mg/(m²·d) ×7d + IDA/DNR等 | 适用于“一般情况可”的患者 [ID:bad3c8da91f42b22] |
| | 中剂量Ara-C巩固 | 适用于预后良好者 | 同上 [ID:bad3c8da91f42b22] |
| | 减低强度预处理allo-HSCT | 适用于一般情况可且有合适供者者 | 同上 [ID:bad3c8da91f42b22] |

> 注：上述所有方案均基于**2017年中国AML指南**，未见其他指南原文提供更细化的剂量或新药（如venetoclax、glasdegib等）在该人群中的证据；图谱证据仅用于疾病分类归属，**不支撑任何治疗决策**。

### 3) 引用的指南原文  

#### （1）老年AML不适合强化疗的定义与推荐方案  
> “年龄≥75岁、一般情况差或具有不良预后因素的患者多采用支持治疗或低强度治疗（如地西他滨或CAG方案等）。2017年中国AML指南推荐的首选方案为：地西他滨[20 mg/（m²·d），5～10天方案]；小剂量化疗±G-CSF(如小剂量AraC为基础的方案—CAG、CHG、CMG等……)；地西他滨联合小剂量化疗等。”  
> —— [ID:bad3c8da91f42b22]

#### （2）缓解后治疗选择（适用于部分达到CR的老年患者）  
> “缓解后可以使用标准剂量的化疗巩固治疗，对于预后良好的患者也可以使用中剂量阿糖胞苷巩固治疗。一般情况可，且有合适供者的患者在缓解后可行降低强度预处理的造血干细胞移植。”  
> —— [ID:bad3c8da91f42b22]

#### （3）适合强化疗的老年患者界定（反向排除标准）  
> “老年患者，年龄小于75岁、一般情况好、不具有不良预后因素（不良染色体核型、前期血液病病史、治疗相关性AML），可用标准3+7方案诱导治疗。”  
> —— [ID:66350e5f0a9c1cf7]

#### （4）支持治疗要点（适用于无法耐受任何抗白血病治疗者）  
> “如果患者不能耐受积极的强化或非强化治疗，则治疗目标是优化生活质量、减少细胞减少相关并发症（输血、抗感染等），并适时引入姑息治疗服务。”  
> —— [ID:c6b85eed93295094]  
>  
> “严重贫血输浓缩红细胞；血小板<10×10⁹/L需输注单采血小板，合并发热时维持≥20×10⁹/L；别嘌醇预防尿酸肾病；及时经验性抗生素治疗发热。”  
> —— [ID:d7ca255fcb9633f9]

#### （5）新药提示（但无老年不适合强化疗人群的具体推荐）  
> “近年来新药如米哚妥林（midostaurin）、GO单抗、CPX-351可用于AML诱导治疗”，但明确限定于“FLT3突变AML”或“年轻患者”（≤59岁或≤70岁），**未扩展至老年不适合强化疗人群**。  
> —— [ID:c6b85eed93295094], [ID:77e7707abde6b1a9]
